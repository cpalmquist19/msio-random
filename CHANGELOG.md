# Changelog

## 1.0.0

- Initial release for Minecraft 1.20.1 on Fabric.
- Added the Cragbeast hostile entity with GeckoLib animations.
- Added the Cragbeast Spawn Egg.
- Added the hatchable Cragbeast Egg block.

### Requirements

- Fabric Loader 0.15.11 or later
- Fabric API 0.92.2+1.20.1 or compatible
- GeckoLib 4.4.9 or compatible
